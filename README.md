# m5-w2-d1-exercise: Controlled and Uncontrolled Forms in React (Week 2 Day 1)

This repository contains the completed in-class demo exercises for Westcliff University WEB 403/603 - Week 2 Day 1.

## Demos Overview

- **Demo 1:** Controlled Component (`NameForm`) with a single text input handling changes via `handleChange` and form submission via `handleSubmit`.
- **Demo 2:** Controlled Component with Multiple Fields (`Reservation`) managing both a checkbox (`isGoing`) and a numeric input (`numberOfGuests`) dynamically using `[name]: value`.
- **Demo 3:** Uncontrolled Component (`NameForm`) using `React.createRef()` to access form field values directly from the DOM without writing an event handler for every state update.
- **Demo 4:** File Upload handling using an Uncontrolled Component (`FileInput`) with `React.createRef()` and `<input type="file" />`, alerting the selected file's name upon submission.
